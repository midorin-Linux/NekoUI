01 🔐
認証
Authentication

JWT (Access Token + Refresh Token) による認証。Access Token は短命（15分）、Refresh Token は長命（30日）。 すべての保護エンドポイントは Authorization: Bearer <token> ヘッダーが必要。

Method
Endpoint
説明
Tags
POST
/auth/register
新規ユーザー登録。email, password, display_name を受け取り access/refresh token を返す
public
POST
/auth/login
ログイン。credentials を検証し token pair を発行
public
POST
/auth/logout
ログアウト。Refresh Token をブラックリストに追加して無効化
auth
POST
/auth/refresh
Refresh Token を使い Access Token を再発行
public
GET
/auth/me
現在ログイン中のユーザー情報を取得
auth
PATCH
/auth/me
プロフィール更新（表示名・パスワード変更・アバター）
auth

03 📨
メッセージ / チャット
Messages & Chat

メッセージの送受信・編集・削除・再生成・ブランチ（会話分岐）・マージを管理。 送信はストリーミング（SSE）と非ストリーミングの両モードに対応。再生成では複数バージョン（世代）を保持できる。

Method
Endpoint
説明
Tags
GET

メッセージ一覧取得。クエリ: limit, before, after, branch_id
auth
POST
/sessions/{id}/messages
メッセージ送信・AI 応答生成。stream=true で SSE に切替可
authstream
GET
/sessions/{id}/messages/{msgId}
特定メッセージ取得（メタデータ・トークン数・所要時間含む）
auth
PATCH
/sessions/{id}/messages/{msgId}
メッセージ本文の編集（編集後に後続メッセージの再生成をトリガー可）
auth
DELETE
/sessions/{id}/messages/{msgId}
単一メッセージ削除
auth
DELETE
/sessions/{id}/messages/{msgId}/after
指定メッセージ以降を全削除（コンテキストの巻き戻し）
authbulk
POST
/sessions/{id}/messages/{msgId}/regenerate
AI 応答を再生成。同メッセージに新バージョンとして追加。stream=true 対応
authstream

/sessions/{id}/messages/{msgId}/versions
再生成で作成されたバージョン一覧取得（世代履歴）

Server-Sent Events ストリーム接続。デルタトークンをリアルタイム配信
